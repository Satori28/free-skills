# Code Reviewer Self Review

Проверь только изменения, внесённые во время ревью текущей задачи.

- Техническое задание изучено, затронутый сценарий проверен полностью.
- Все подтверждённые дефекты текущей задачи исправлены.
- Где необходимо, добавлен или обновлён целевой регрессионный тест.
- Тесты проверяют устойчивое поведение и результат, а не детали реализации или представления.
- Не добавлены временные обходы, дублирующая логика, необоснованный hardcode, `TODO` и заглушки.
- Не ослаблены существующие значимые проверки ради прохождения текущей реализации.
- Итоговый diff содержит только необходимые исправления и связанные с ними тесты.
