# Motion-видео: старт для агента и пользователя

Этот Skill — карта инструментов и возможностей. Исходники конкретного ролика и его `AGENTS.md`/`README.md` определяют фактические команды и файлы. Подробный монтажный рецепт агенту здесь не нужен.

## При первом обращении

1. Определи, есть ли готовый проект. Прочти его `AGENTS.md`, `README.md` и манифест; узнай выбранный стек, исходную композицию, ассеты и команду экспорта. Если проекта нет, для 2D интерфейсов и текста предложи HyperFrames или Motion Canvas; 3D добавляй, когда нужен объёмный объект.
2. Открой [SETUP.md](SETUP.md): проверь FFmpeg/ffprobe и зависимости **выбранного** стека (Node.js для JS/TS, Python для Manim). Установи недостающее, используя версию/lockfile существующего проекта. Не устанавливай все альтернативные движки без задачи. HeyGen и другие внешние каталоги подключай только при необходимости; доступ к аккаунту предоставляет пользователь.
3. Коротко сообщи, что готово к работе и что требует подключения. Предложи пользователю меню из [CAPABILITIES.md](CAPABILITIES.md), подстроенное под доступные инструменты. После первого черновика снова назови 3–5 конкретных правок, которые можно попросить обычными словами или показать на скриншоте.

## Что за что отвечает

| Инструмент | Роль |
| --- | --- |
| **HyperFrames + HTML/CSS** | Композиция 2D-сцен: текст, карточки, интерфейсы, слои изображений и отдельные звуковые дорожки. Хранит тайминг и экспортирует итоговый MP4. |
| **GSAP внутри HyperFrames** | Движение элементов и «камеры»: въезды, удары, падение, масштаб, поворот и акценты по музыкальным долям. Исходник остаётся редактируемым по объектам. |
| **Реестр HyperFrames** | Готовые основы для сложных элементов и переходов. В Aviasales адаптировали механизм перекидного табло и вспышку перехода; компоненты курсора и приближения использовали как образцы, а не вставляли целиком. |
| **Генератор изображений** | Прозрачные PNG для самолёта, острова, пальмы, чемоданов, персонажа и руки со штампом. Отдельные вырезанные объекты затем анимируются в HyperFrames; такая сцена не требует Blender, пока не нужна смена ракурса или настоящая объёмная геометрия. |
| **Официальные бренд-ассеты** | Логотипы и значки берутся из проверяемого источника и сохраняются локально с происхождением. Фирменный знак не стоит доверять генератору изображений. |
| **Motion Canvas + TypeScript** | Альтернатива для 2D с редактором и шкалой времени, удобная для программных сцен и синхронизации. |
| **Canvas JS / p5.js** | Рисованная графика, где каждый кадр вычисляется кодом. |
| **Manim + Python** | Схемы, объясняющая графика и математические объекты. |
| **Blender** | Нужен, когда объект должен менять ракурс, реально вращаться в 3D или зависеть от объёмного света. В финальном Aviasales-ролике не применялся: динамику самолёта и острова дали прозрачные изображения, слои и движение камеры в HyperFrames. |
| **Remotion + React** | Повторяемые ролики из React-компонентов, если проект уже выбрал этот стек. |
| **HeyGen / локальные звуковые библиотеки** | Источники музыки и коротких SFX. В Aviasales музыкальный бит и свиши взяты из HeyGen, чёткие удары и щелчки — из Kenney; файлы сохранены в проекте и не требуют обращения к сервису при рендере. |
| **Python + FFmpeg** | Собирают отдельный SFX-файл из локальных семплов и обрезают звук для нужного момента. Музыка, вступительный эффект и SFX остаются разными дорожками, поэтому их можно менять независимо. |
| **HyperFrames CLI + ffprobe** | Снимки конкретных моментов, проверка композиции, рендер; затем проверка длительности, разрешения, кодеков и полного декодирования MP4. Снимки подтверждают отдельные кадры, а не заменяют просмотр ролика и прослушивание. |

Если доступны специализированные skills, используй `hyperframes` и его компоненты для HyperFrames, `javascript-animation` для Canvas JS, `soundtrack` для музыки. Ссылки и команды установки — в [SETUP.md](SETUP.md). Не обещай пользователю подключённый сервис или готовый голос, пока не проверил доступность.
