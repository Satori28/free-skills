# Motion-видео: старт для агента и пользователя

Этот Skill — карта инструментов и возможностей. Исходники конкретного ролика и его `AGENTS.md`/`README.md` определяют фактические команды и файлы. Подробный монтажный рецепт агенту здесь не нужен.

## При первом обращении

1. Определи, есть ли готовый проект. Прочти его `AGENTS.md`, `README.md` и манифест; узнай выбранный стек, исходную композицию, ассеты и команду экспорта. Если проекта нет, для 2D интерфейсов и текста предложи HyperFrames или Motion Canvas; 3D добавляй, когда нужен объёмный объект.
2. Открой [SETUP.md](SETUP.md): проверь FFmpeg/ffprobe и зависимости **выбранного** стека (Node.js для JS/TS, Python для Manim). Установи недостающее, используя версию/lockfile существующего проекта. Не устанавливай все альтернативные движки без задачи. HeyGen и другие внешние каталоги подключай только при необходимости; доступ к аккаунту предоставляет пользователь.
3. Коротко сообщи, что готово к работе и что требует подключения. Предложи пользователю меню из [CAPABILITIES.md](CAPABILITIES.md), подстроенное под доступные инструменты. После первого черновика снова назови 3–5 конкретных правок, которые можно попросить обычными словами или показать на скриншоте.

## Что за что отвечает

| Инструмент | Роль |
| --- | --- |
| **HyperFrames + HTML/CSS + GSAP** | Основная сборка 2D-сцен, типографики, UI, переходов, тайминга и слоёв звука. |
| **Motion Canvas + TypeScript** | Альтернатива для 2D с редактором и шкалой времени, удобная для программных сцен и синхронизации. |
| **Canvas JS / p5.js** | Рисованная графика, где каждый кадр вычисляется кодом. |
| **Manim + Python** | Схемы, объясняющая графика и математические объекты. |
| **Blender** | 3D-персонаж, предмет, свет и камера; результат можно встроить в 2D-композицию. |
| **Remotion + React** | Повторяемые ролики из React-компонентов, если проект уже выбрал этот стек. |
| **FFmpeg + ffprobe** | Сборка, конвертация, звук и техническая проверка готового файла. |
| **HeyGen или локальные медиа** | Дополнительный источник музыки, голоса и других ассетов; не обязателен для рендера. |

Если доступны специализированные skills, используй `hyperframes` и его компоненты для HyperFrames, `javascript-animation` для Canvas JS, `soundtrack` для музыки. Ссылки и команды установки — в [SETUP.md](SETUP.md). Не обещай пользователю подключённый сервис или готовый голос, пока не проверил доступность.
